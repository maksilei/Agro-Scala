# Agro Scala

Landing page estatica da Agro Scala, pronta para publicacao no GitHub Pages.

## GitHub Pages

Configuracao sugerida:

1. Acesse `Settings > Pages`.
2. Em `Build and deployment`, selecione `Deploy from a branch`.
3. Escolha a branch `main`.
4. Escolha a pasta `/root`.
5. Salve e aguarde a URL `https://maksilei.github.io/Agro-Scala/`.
